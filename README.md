# Насколько защитный контекст улучшает модель Expected Goals?

Построение и сравнение футбольных xG-моделей на основе геометрии удара,
характеристик момента и расположения защитников и вратаря в StatsBomb Open Data.

Пет-проект для ИАД ОГО, Бюрчиев Тимур, БПИ 248.

## Исследовательский вопрос

> Какую дополнительную прогностическую ценность дают расположение защитников и
> вратаря по сравнению с моделью, которая знает только геометрию и характеристики удара?

Это исследование качества прогнозирования, а не причинно-следственное исследование.
Успешным считается любой честный результат: защитный контекст может дать большое,
небольшое или статистически неубедительное улучшение. Проект не обязан
подтверждать исходную гипотезу и не обязан превосходить `statsbomb_xg`.

Полная постановка задачи, правила и критерии готовности — в
[`PROJECT_CONTEXT.md`](PROJECT_CONTEXT.md).

## Данные

Единственный источник — официальный репозиторий
[StatsBomb Open Data](https://github.com/hudl/open-data), привязанный к
неизменяемой ревизии (commit SHA в `configs/data.yaml`).

Данные загружаются скриптом, вручную ничего скачивать не нужно. Репозиторий
источника не клонируется целиком: в зафиксированной ревизии он содержит около
12.8 ГБ событий и 3.2 ГБ файлов StatsBomb 360. Сырые данные не коммитятся.

Подробности и атрибуция — в [`DATA_SOURCES.md`](DATA_SOURCES.md).

## Установка

```bash
python -m venv .venv
```

```bash
.venv/Scripts/python.exe -m pip install -e ".[dev]"
```

На Linux и macOS вместо `.venv/Scripts/python.exe` используется `.venv/bin/python`.

## Воспроизведение

Загрузка метаданных и оценка объёма (около 7 МБ):

```bash
python scripts/download_data.py --config configs/data.yaml --metadata-only
```

Аудит данных — генерирует `reports/data_audit.md` и таблицы в `reports/tables/`:

```bash
python scripts/audit_data.py --config configs/data.yaml
```

Загрузка утверждённой выборки (работает только после `selection.approved: true`):

```bash
python scripts/download_data.py --config configs/data.yaml --selection
```

Тесты и линтер:

```bash
pytest -q
```

```bash
ruff check . && ruff format --check .
```

## Структура

```text
src/xg_context/   переиспользуемая логика: конфигурация, загрузка, аудит, геометрия, признаки
scripts/          воспроизводимые точки входа
configs/          источник и параметры аудита (data.yaml), эксперимент (experiment.yaml)
reports/          отчёты, таблицы и графики
tests/            unit-тесты target mapping, геометрии, загрузчика, аудита и leakage
notebooks/        анализ и повествование (этапы 2–5)
data/             локальные данные, в Git не попадают
```
