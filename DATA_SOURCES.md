# Источники данных

## StatsBomb Open Data

Единственный источник данных проекта — официальный репозиторий
**StatsBomb Open Data**:

- репозиторий: <https://github.com/hudl/open-data>
- документация формата: <https://github.com/hudl/open-data/tree/master/doc>
- лицензия и условия использования: файл `LICENSE.pdf` в репозитории источника

Kaggle-копии, зеркала и заранее подготовленные датасеты как основной источник
не используются (спецификация, раздел 5.1).

## Зафиксированная ревизия

StatsBomb обновляет Open Data, поэтому проект привязан к неизменяемой ревизии:

| Параметр | Значение |
| --- | --- |
| Репозиторий | `hudl/open-data` |
| Commit SHA | `b0bc9f22dd77c206ddedc1d742893b3bbe64baec` |
| Permalink | <https://github.com/hudl/open-data/tree/b0bc9f22dd77c206ddedc1d742893b3bbe64baec> |
| Дата фиксации | 2026-08-23 |

SHA хранится в `configs/data.yaml` и попадает в `data/data_manifest.json`.
Все URL строятся от него, а не от ветки: загрузка с `master` сделала бы
результаты невоспроизводимыми.

## Что и как скачивается

Репозиторий источника **не клонируется целиком**: в зафиксированной ревизии он
содержит около 12.8 ГБ событий и 3.2 ГБ файлов StatsBomb 360.

| Слой | Файлы | Объём | Когда скачивается |
| --- | --- | ---: | --- |
| Соревнования | `data/competitions.json` | ~14 КБ | всегда |
| Матчи | `data/matches/{competition_id}/{season_id}.json` | ~7 МБ | всегда, целиком |
| События | `data/events/{match_id}.json` | ~3 МБ на матч | только для нужных матчей |
| StatsBomb 360 | `data/three-sixty/{match_id}.json` | ~7.5 МБ на матч | по отдельному решению |

Перечень файлов и их размеры получаются одним запросом git-tree к GitHub API,
поэтому объём любой загрузки известен заранее, до скачивания.

Скачанные файлы кешируются в `data/raw/<первые 12 символов SHA>/` с сохранением
структуры путей источника. Повторный запуск использует кеш.

## Что не попадает в Git

Сырые и обработанные данные исключены через `.gitignore`. В репозитории проекта
хранятся только `data/data_manifest.json`, конфигурации, небольшие итоговые
таблицы и графики. Полный исходный датасет внутри проекта не распространяется.

## Атрибуция

При публикации результатов необходимо указывать StatsBomb как источник данных и
соблюдать условия StatsBomb Open Data. Лицензия кода этого репозитория (MIT)
распространяется только на код и не заменяет условия использования данных.

Рекомендуемая формулировка:

> Данные предоставлены StatsBomb (StatsBomb Open Data).
